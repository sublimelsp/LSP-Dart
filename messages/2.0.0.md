Breaking changes:

- The key used to override LSP-Dart settings in project settings has changed from `Dart` to `LSP-Dart`.
  If you use project-specific overrides for LSP-Dart, you have to rename the key for them to apply:

  Before:

  ```jsonc
  {
      "settings": {
          "LSP": {
              "Dart": {
                  // ...
              }
          }
      }
  }
  ```

  After:

  ```jsonc
  {
      "settings": {
          "LSP": {
              "LSP-Dart": {
                  // ...
              }
          }
      }
  }
  ```
